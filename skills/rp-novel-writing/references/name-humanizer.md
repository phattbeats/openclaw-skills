# Name humanizer: de-AI-ing a cast list

LLM-cowritten fiction converges on a recognizable name pool. Readers who use AI recognize it
instantly, and it will only get more recognizable. Audit the full cast (including one-line minor
characters) and propose replacements for approval.

## Flag list (non-exhaustive; the smell, not just the list)

High-frequency AI defaults: Marcus, Elara, Kael, Kai, Lyra, Lira, Aria, Aris, Coraline, Thorne
(surname), Aelric, Alaric, Theron, Caelum, Cassius, Seraphina, Isolde, Ryker, Jax, Wren, Sable,
Ember, Raven, Ash, Vex, Zephyr, Orion, Luna, Nova, Silas, Elias, Evelyn "Eve", Chen (as the
default Asian surname), Voss, Draven.

The smell beyond the list: -ric/-ael/-yn endings clustering; celestial/gemstone/nature nouns as
names; names that are one letter off a famous fantasy name; every woman ending in -a; villains
with Latin-adjacent names; the too-perfect thematic name (the spy named Sable).

Also audit **place names**: LLMs borrow real IP wholesale — D&D (Mirabar, Adbar, Neverwinter),
Tolkien, Warhammer. For anything the user may publish, flag these explicitly. And flag
**placeholder realm names** (Terra, Aetheria, Eldoria) for proper naming.

## Building replacements

1. **Derive each culture's naming register from the names the author already chose and loves.**
   If the human court runs on plain Anglo names (Brandon, Catherine, Frederick, Margaret), new
   human names come from that register (Dennet, Walter, Rosamund, Maud); if the dwarves are
   Norse (Helja, Rangrim, Aldrik), stay Norse. Consistency of register does more for "human-
   written" feel than any individual name.
2. **Keep good surnames when only the first name is flagged** (Marcus Holt → Dennet Holt) —
   halves the reader-facing churn.
3. **Match the name to the characterization**, not the role: the unglamorous killer gets a
   plain worn name, not a menacing one; nobody generates "Maud", which is exactly why it works.
4. **In-world aliases get a pass** (a spy's work name, a singer's stage name) if the text frames
   them as chosen names — chosen names are allowed to be thematic.
5. **Check collisions** old and new: same name on two characters, new name colliding with an
   existing family (renaming a lord "Pemberton" when a Lady Pemberton exists), initials in
   letters/signatures that need updating (C.T. → R.V.).
6. Deliberate echoes (two characters sharing a name meaningfully) are a craft decision — surface
   them and ask; if kept, suggest the text acknowledge the echo once so it reads as intentional.

## Process

Present a table: current name · why flagged · 2-3 options with one-line rationales · recommended
pick. Get approval (a quick multiple-choice round for the majors, batch approval for minors).
Log approved renames in the story bible as the canonical map, including derived forms
(possessives, nicknames, initials, "Lady X" forms). Apply during novelization, then grep the
final manuscript for every old name — zero hits before delivery.
